# Civitas 2.0

Civitas 2.0 is a concept prototype for a next-generation economic system app. It frames the economy around public value, cooperative capital, resilience, and digital inclusion instead of only GDP and extractive growth.

## Features
- Interactive policy stack simulation
- Public goods and community wealth tracking
- Sector health dashboard
- Forecast and resilience overview
- Responsive glassmorphism UI

## Run locally
1. Open the folder in a browser, or serve it with a local web server.
2. From this directory, run:

```bash
python -m http.server 8000
```

3. Visit: http://localhost:8000

## Project structure
- `index.html` – app layout
- `styles.css` – visual design and responsive styling
- `app.js` – economic simulator logic

## Concept
This app is designed as an innovation prototype, not a full production financial system. It demonstrates how a public-interest economy could be visualized and tested through policy decisions.
